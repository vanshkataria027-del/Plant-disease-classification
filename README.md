# 🌿 Plant Disease Classifier

A CNN-based deep learning model to detect plant diseases from leaf images.

## Features
- Classifies 38 plant disease categories
- Built with TensorFlow/Keras
- Streamlit web interface

## Dataset
PlantVillage Dataset - 54,000+ leaf images

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
- Python
- TensorFlow/Keras
- Streamlit
- OpenCV
